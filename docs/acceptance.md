# Acceptance ledger

The contract is [SPEC.md](../SPEC.md). None of the task identifiers is advertised as a calibrated release. This ledger separates executable package behavior from empirical release evidence; it is not a substitute for the original acceptance gates.

The user-directed move to c3 is documented in [c3-handoff.md](c3-handoff.md).
Ghost's remaining evaluation group is held while the current pretrained ResNet18
ADE model finishes. A persistent watcher will stop its multi-model queue after
that model's verifier succeeds; remaining evaluations require relocated,
revalidated plans on c3. Boundary and transfer receipts under
`outputs/acceptance/c3-handoff-20261023/` distinguish preparation from completion.

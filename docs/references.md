# Reference and source provenance

Algorithms in this package are independently implemented. The package does not import the DINOv3 training/evaluation framework, Probe3D, VISSL, or an experiment tracker. A reference citation does not imply published-score parity.

| Component | Reference | Reuse and differences |
| --- | --- | --- |
| CLEVR targets | [VISSL revision 09270ed25a6c2cf71263d955b64cbe076d34ac45](https://github.com/facebookresearch/vissl/tree/09270ed25a6c2cf71263d955b64cbe076d34ac45/extra_scripts/datasets), MIT | Count is 3–10 objects, encoded as count minus three. Distance uses `bisect_left([8, 8.5, 9, 9.5, 10, 100], min(pixel_coords[2]))`. The benchmark's development/final split differs from VISSL's preparation output. No VISSL code is vendored. |
| ImageNet-100 class membership | [CMC revision 7b227be0b10ef4e526c72af07664f5079ed9ee09](https://github.com/HobbitLong/CMC/blob/7b227be0b10ef4e526c72af07664f5079ed9ee09/imagenet100.txt) | The synset list is vendored as factual class identifiers and pinned by SHA-256. Numeric targets follow sorted synset order. Sample banks are benchmark-specific. |
| ImageNet readable names | [TensorFlow/Keras class index](https://storage.googleapis.com/download.tensorflow.org/data/imagenet_class_index.json) | Factual synset/name mapping is vendored with SHA-256 `a1e7a966a1f601d39e4b43e119b3e7dd4a2ad3ea08cf69847cbaf021013767bc`. |
| VOC2012 acquisition | [torchvision v0.24.0 source](https://github.com/pytorch/vision/blob/v0.24.0/torchvision/datasets/voc.py), BSD-3-Clause | Archive name, official URL, published MD5, and segmentation split layout. Loader and preparation code are original. |
| ADE20K | [Scene parsing challenge](https://sceneparsing.csail.mit.edu/) | Uses ADEChallengeData2016, 150 classes; source label zero is ignored, labels 1–150 become 0–149. The complete official archive download independently matched the locally measured SHA-256 on 2026-10-21. |
| SPair-71k | [Official source](https://cvlab.postech.ac.kr/research/SPair-71k/) | Official archive downloaded on 2026-10-21, SHA-256 `d145eebe4d7d02ff0b9e2746dd3d72cfcb872df0dcfd6f3227576eb594408809`, 226,961,117 bytes. Train/validation/test contain 53,340/5,384/12,234 pairs. Pooled-correspondence aggregation differs from Probe3D's category average. |
| CLEVR acquisition | [Official dataset](https://cs.stanford.edu/people/jcjohns/clevr/), [TensorFlow Datasets checksums](https://github.com/tensorflow/datasets/blob/master/tensorflow_datasets/datasets/clevr/checksums.tsv) | Main CLEVR_v1.0 image/scene archive, pinned SHA-256 and byte size in `sources.yaml`. |
| Global probing | [DINOv3 evaluation](https://github.com/facebookresearch/dinov3/blob/main/dinov3/eval/log_regression.py) | Reference for fixed-feature probing. This package implements its own AdamW recipe, standardization, development partition, seed search, and artifact lifetime. Logistic-regression score parity is not claimed. |
| Correspondence geometry | [Probe3D revision a1f14640076e38b8bc07b66d0fe2d01d15691e9d](https://github.com/mbanani/probe3d/tree/a1f14640076e38b8bc07b66d0fe2d01d15691e9d), MIT | The acceptance harness executes only checksum-verified `compute_errors` and `argmax_2d` functions. Alignment explicitly changes source normalization order, `align_corners`, border padding, and target half-cell offsets. All 1,920 predicted locations and PCK counts agree across 48 synthetic cases, including raster ties and boundary keypoints. This does not establish dataset/preprocessing or published-score parity. The separate aggregation test gives pooled PCK 75% where the category average is 50%. Required attribution is retained in [licenses/probe3d.txt](licenses/probe3d.txt). |

Dataset access and licenses remain those of their original publishers. Source archives supplied by a user are never deleted; only archives downloaded into bench-owned staging are removed after successful source extraction.

`outputs/acceptance/source-route-full-check.json` records complete streamed official VOC and ADE archive checksums, resolved download URLs, byte counts, and elapsed time. The streams retained no duplicate archives. CLEVR and SPair were acquired from their pinned routes and used for real source preparation.
